## 1. 개발 환경 구축 & 빌드 (Dev Environment & Build)

### 🛠️ 개발 도구 설치 및 버전 확인

C++ 개발 및 디버깅을 위한 필수 패키지를 설치합니다.

Bash

```
# 필수 개발 도구 한 번에 설치
sudo apt install -y build-essential cmake gdb valgrind git

# 설치 유무 및 버전 확인
g++ --version
cmake --version
gdb --version
valgrind --version
```

| **패키지명** | **역할 및 설명** |
| --- | --- |
| `build-essential` | C/C++ 컴파일러(`g++`, `gcc`) 및 빌드 필수 라이브러리 패키지 |
| `cmake` | 이종 플랫폼을 지원하는 빌드 시스템 생성 도구 |
| `gdb` | GNU 디버거 (코드 실행 흐름 추적 및 에러 분석) |
| `valgrind` | 메모리 누수(Memory Leak) 및 디버깅 분석 도구 |
| `git` | 소스코드 버전 관리 시스템 |

### ⚙️ C++ 컴파일 명령어

작성한 C++ 소스 코드를 실행 파일로 빌드(Build)하는 기본 명령어입니다.

Bash

```
g++ -Wall -Wextra -std=c++17 -o hello ./hello_world.cpp
```

- **`Wall -Wextra`**: 컴파일 시 발생할 수 있는 주요 경고(Warning) 메시지를 활성화
- **`std=c++17`**: C++17 표준 문법을 적용하여 컴파일
- **`o hello`**: 빌드 결과물로 생성될 실행 파일 이름을 `hello`로 지정
- **`./hello_world.cpp`**: 컴파일할 대상 소스 코드 파일 경로

> **💡 참고:** 컴파일 오류 발생 시 빌드가 진행되지 않으며, 터미널 출력의 **가장 마지막 줄**에 주요 원인이 표기되는 경우가 많습니다.
> 

## 2. C++ 기본 입출력 및 자료형 (I/O & Data Types)

### 📌 입출력 및 기본 구조

- `#include <iostream>`: 표준 입출력 스트림 라이브러리 헤더 파일
- `std`: C++ 표준 라이브러리의 네임스페이스(Namespace)
- `std::cout` / `std::cin`: 터미널 출력 / 입력 스트림
- `std::endl`: 줄바꿈 문자를 출력하고 출력 버퍼를 비움(Flush)
- `return 0;`: `main` 함수가 정상적으로 종료되었음을 OS에 전달

### 📊 C++ 주요 자료형 요약

| **분류** | **자료형** | **크기** | **설명** |
| --- | --- | --- | --- |
| **정수형** | `short` | 2 Byte | 작은 범위 정수 |
|  | `int` | 4 Byte | 기본 정수형 |
|  | `long` | 4~8 Byte | 큰 범위 정수 (OS/아키텍처에 따라 변동) |
|  | `unsigned` | - | 부호 없는 정수 (음수 불가, 양수 표현 범위 2배 증가. ID, 개수 등에 사용) |
| **실수형** | `float` | 4 Byte | 단정밀도 실수 (리터럴 뒤에 `f` 붙임. 예: `3.14f`) |
|  | `double` | 8 Byte | 배정밀도 실수 (기본 실수형) |
| **논리형** | `bool` | 1 Byte | `true` (1) / `false` (0) 저장 |
| **문자(열)** | `char` | 1 Byte | 단일 문자 (작은따옴표 `'A'` 사용) |
|  | `std::string` | 가변 | 문자열 클래스 (큰따옴표 `"Hello"` 사용, `#include <string>`) |

> **❓ 주요 Q&A**
> 
> - **`unsigned`에 음수 값을 넣으면 어떻게 되나요?**
>     
>     `unsigned`는 부호 비트가 없으므로 음수 입력 시 언더플로우(Underflow)가 발생하여 자료형이 표현할 수 있는 가장 큰 값 근처의 이상 수치로 변환됩니다.
>     
> - **`float` 뒤에 `f`를 붙이는 이유는?**
>     
>     C++에서 소수점 리터럴(예: `3.14`)은 기본적으로 `double`(8byte)로 인식됩니다. `f`를 붙이지 않으면 `double`에서 `float`으로의 자동 형변환 과정에서 데이터 손실 경고가 발생할 수 있습니다.
>     
> - **적절한 자료형 선언이 중요한 이유**
>     
>     `int` 변수에 소수점을 넣으면 데이터 손실이 일어나고, 반대로 단순 정수 데이터에 `double`을 남발하면 필요 이상의 메모리(8byte)를 점유하여 메모리 낭비가 발생합니다.
>     

### 🔍 변수 및 메모리 제어 키워드

C++

```
// 1. 배열 선언 및 sizeof를 이용한 크기 확인
int readings[5] = {10, 20, 30, 40, 50};
std::cout << "readings[0] size: " << sizeof(readings[0]) << " bytes" << std::endl; // 4 bytes

// 2. 상과 변수 자동 추론
const int MAX_VALUE = 100;      // 변수를 수정 불가능한 상수로 지정
constexpr int LIMIT = 50 * 2;    // 컴파일 시점에 상수를 평가하여 강력하게 고정
auto current_speed = 80.5;      // 컴파일러가 자동으로 double 타입으로 추론

// 3. Scope (영역) 중첩 및 변수 가리기(Shadowing)
int number = 1;
{
    int number = 2; // 블록 내에서 중첩 선언 (블록이 끝나면 파괴됨)
    std::cout << "Inner Number: " << number << std::endl; // 2 출력
}
std::cout << "Outer Number: " << number << std::endl; // 1 출력
```

## 3. 연산자 & 제어문 (Operators & Control Flow)

### 📐 연산자 활용

- **실수 나머지 연산 (`fmod`)**: 정수형 `%` 연산자와 달리 실수형 나머지는 `#include <cmath>`의 `fmod(a, b)` 함수 사용
- **전위/후위 증감 연산자**:
    - `++i`: 값을 먼저 1 증가시킨 후 문장 실행
    - `i++`: 문장을 먼저 실행한 후 값을 1 증가
- **`std::boolalpha`**: `bool` 결과를 `1/0` 대신 `true/false` 문자열로 출력
- **삼항 연산자 (`조건 ? 참 : 거짓`)**: 조건식의 결과에 따라 값을 선택

C++

```
#include <iostream>
#include <cmath>

int main(){
    float a = 5.5, b = 10.1;
    std::cout << "fmod: " << fmod(a, b) << std::endl; // 실수 나머지 연산

    bool battery_low = true;
    std::cout << "Battery Status: " << std::boolalpha << battery_low << std::endl; // true 출력

    bool lidar_ok = true;
    std::cout << "Robot Status: " << (lidar_ok ? "OK" : "NOT OK") << std::endl;

    return 0;
}
```

### 🔀 조건문 및 반복문

#### 1) `if - else if - else` 문

C++

```
int batteryLevel = 75;

if (batteryLevel == 100) {
    std::cout << "Battery is full" << std::endl;
} else if (batteryLevel >= 50) {
    std::cout << "Battery is half full" << std::endl;
```

#### 2) `switch - case` 문

> **⚠️ 디버깅 노트 (수정 사항)**
> 
> - 문자는 큰따옴표(`" "`)가 아닌 **작은따옴표(`' '`)**로 감싸야 합니다 (`char` 타입 규격).
> - `case` 문 끝에는 세미콜론(`;`)이 아닌 **콜론(`:`)**을 작성해야 합니다.

C++

```
char lidar_code = 'F'; // 문자(char)는 작은따옴표 사용

switch (lidar_code) {
    case 'F':
        std::cout << "Front Lidar Selected" << std::endl;
        break;
    case 'B':
        std::cout << "Back Lidar Selected" << std::endl;
        break;
    default:
        std::cout << "Unknown Lidar Code" << std::endl;
        break;
}
```

#### 3) `do-while` 문

C++

```
int count = 0;
do {
    // 조건 비교 전 무조건 최소 1회 실행
    std::cout << "Execution count: " << count << std::endl;
    count++;
} while (count < 3);
```

## 4. C++ 메모리 모델 & 클래스 기초 (Memory & Class)

### 🧠 스택(Stack) vs 힙(Heap) 메모리 비교

C++

```
#include <iostream>
#include <vector>

class Motor {
public:
    Motor() {
        std::cout << "Motor initialized." << std::endl;
    }
    ~Motor() {
        std::cout << "Motor destroyed." << std::endl;
    }
};

// 1. 스택 메모리 활용 함수
void control_loop(){
    std::cout << "Starting control loop..." << std::endl;

    double time_step = 0.1;
    (void)time_step; // 미사용 변수 컴파일러 경고 억제 구문

    Motor motor; // [스택 할당] new 없이 선언. 함수 종료(}) 시 자동으로 소멸자 호출 및 해제
}

// 2. 힙 메모리 활용 메인 함수
int main(){
    control_loop(); // 스택 객체 생성 및 자동 해제 흐름 확인

    // [힙 동적 할당] new를 통해 힙 영역에 객체 생성 후 주소값을 포인터에 저장
    Motor* motor_ptr = new Motor();

    std::cout << "Created motor instance at: " << motor_ptr << std::endl;

    // [힙 수동 해제] new로 할당한 메모리는 delete를 통해 명시적으로 해제해야 함 (수동 소멸자 호출)
    delete motor_ptr;

    std::cout << "Motor instance deleted." << std::endl;

    return 0;
}
```

| **구분** | **스택 (Stack) 할당** | **힙 (Heap) 할당** |
| --- | --- | --- |
| **할당 방식** | `Motor motor;` | `Motor* motor_ptr = new Motor();` |
| **관리 주체** | 시스템(컴파일러)이 자동 관리 | 개발자가 직접 관리 |
| **해제 시점** | 중괄호(`}`) 영역(Scope)을 벗어날 때 자동 해제 | `delete motor_ptr;` 명령 실행 시 해제 |
| **장단점** | 처리가 빠르고 안전함 | 자유로운 메모리 제어 가능 / 해제 누락 시 **메모리 누수** 발생 |
