## 2. LiDAR 데이터 생성 및 가공 분석

### 🎲 난수 생성과 데이터 모사
* **`np.random.default_rng(0)`**: 최신 NumPy에서 권장하는 난수 생성 방식입니다. 시드(Seed) 값을 `0`으로 고정하여 시간이 지나도 항상 동일한 데이터셋을 생성합니다.
* **`scan = rng.random(360) * 10`**:
  * `360`: $360^\circ$ 회전 라이다 센서의 측정 채널 개수를 의미합니다.
  * `* 10`: $0 \sim 1$ 사이의 난수에 10을 곱하여 $0 \sim 10\text{m}$ 범위의 스캔 거리를 모사합니다.
* **`angles = np.linspace(0, 2*np.pi, 360)`**: $0$부터 $2\pi$($360^\circ$)까지 균등하게 360개로 쪼개어 라이다 스캔 각도 배열을 만듭니다.

```python
import numpy as np

# 난수 생성기 초기화 (시드 0 고정)

# 0~10m 범위의 360개 스캔 거리 생성
scan = rng.random(360) * 10

# 0 ~ 2π 사이의 360개 각도 생성
angles = np.linspace(0, 2 * np.pi, 360)
print('scan shape:', scan.shape)  # (360,)

🔄 2D 회전행렬과 거리 보존 성질$$R = \begin{bmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{bmatrix}$$점군이 $(N, 2)$ 차원으로 행 방향으로 쌓여 있는 경우, 올바른 반시계 방향 회전을 적용하기 위해 xy @ R.T(전치행렬 곱)를 수행합니다.회전 변환 후 원점과의 거리(np.linalg.norm)는 변하지 않으므로 d0와 d1의 차이는 $0.0$이 됩니다.Pythonth = np.radians(45)
c, s = np.cos(th), np.sin(th)
