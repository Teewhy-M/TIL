## 1. C++ 핵심 개념 복습

### 1) 상속과 다형성 (Inheritance & Polymorphism)

#### `class Lidar : public Sensor` 구문의 의미

- **상속 선언**: `Sensor` 부모(Base) 클래스를 `public` 접근 제어자로 상속받아 `Lidar` 자식(Derived) 클래스를 정의한다는 뜻입니다.
- **효과**: `Lidar` 클래스는 `Sensor` 클래스의 `protected` 및 `public` 멤버(변수, 함수)를 그대로 물려받으며, 부모의 순수 가상 함수를 자신에 맞게 오버라이딩(재정의)할 수 있게 됩니다.

#### 다형성 (Polymorphism)

- **정의**: '여러 가지 형태를 가질 수 있는 능력'을 의미합니다.
- **C++에서의 의미**: 동일한 형태의 코드(함수 호출)를 실행하더라도, 실제 연결되어 있는 객체 종류에 따라 서로 다르게 동작하는 성질입니다.
- **비유**: 하나의 리모컨 전원 버튼으로 TV, 에어컨, 오디오를 모두 켤 수 있는 것과 같습니다. (호출 인터페이스는 동일하지만 각 기기별 동작은 상이)

#### 부모 포인터 (Base Class Pointer)

- **정의**: 자식 객체의 메모리 주소를 가리키고 있는 부모 타입의 포인터 변수 (`Sensor* ptr = new Lidar();`)입니다.
- **`Sensor*`가 부모 포인터인 이유**:
    - 클래스 구조상 `Sensor`가 최상위에 위치한 기반 클래스이기 때문입니다.
    - `Sensor` 클래스 내부에 `virtual ... = 0` (순수 가상 함수)이 선언되어 있어 단독 객체 생성이 불가능하므로, `IMU`, `Lidar` 같은 실체 자식 클래스들의 부모(Base Class) 역할을 담당하게 됩니다.

### 2) 포인터, 참조자, `const` 완벽 정리

#### ① 포인터 (Pointer - )

- 메모리의 **실제 주소값**을 저장하는 변수입니다. ( 기호의 위치와 쓰임에 따라 의미가 달라지므로 주의)
- **주소 연산자 (`&`)**: 변수 앞에 붙이면 해당 변수가 위치한 메모리 주소를 반환합니다.
- **역참조 연산자 ()**: 포인터 변수 앞에 붙이면 해당 주소로 찾아가 실제 들어있는 값을 읽거나 수정합니다.
- **특징**: `nullptr`로 초기화할 수 있으며, 실행 중 가리키는 대상을 자유롭게 바꿀 수 있습니다 (재할당 가능).

#### ② 참조자 (Reference - `&`)

- 이미 존재하는 변수에 대해 생성하는 별명(Alias)입니다.
- 선언 시점에 지정한 원본 변수의 메모리 공간을 그대로 공유하며, 별명을 통해 값을 바꾸면 원본 값도 함께 변경됩니다.
- **특징**:
    - 선언과 동시에 반드시 초기화해야 하며, 대상이 없는 참조자는 존재할 수 없습니다.
    - `NULL` 또는 `nullptr` 할당이 불가능합니다 (항상 유효한 객체 지칭).
    - 한 번 특정 변수에 바인딩되면 다른 변수로 변경(재바인딩)할 수 없습니다.
    - 역참조 연산자() 없이 일반 변수와 동일한 문법(`.`)으로 간결하게 접근합니다.

#### ③ `const` (상수화)와 포인터의 조합

`const`는 변수를 읽기 전용(Read-Only)으로 잠그는 키워드입니다. `*` 기호를 기준으로 `const`의 위치에 따라 제어 대상이 달라집니다.

| **구문** | **const 위치** | **의미 및 특징** | **코드 예시** |
| --- | --- | --- | --- |
| **`const int* ptr`** | `*` **왼쪽** | **상수를 가리키는 포인터**

포인터가 가리키는 **값 변경 불가** (`ptr`을 통한 값 수정 막음, 가리키는 주소 변경은 가능) | `//*ptr = 50; (❌)`

`ptr = &b; (⭕)` |
| **`int* const ptr`** | `*` **오른쪽** | **상수 포인터**

포인터 변수 자체의 **주소 변경 불가** (가리키는 대상 고정, 값 수정은 가능) | `*ptr = 50; (⭕)`

`//ptr = &b; (❌)` |
| **`const int* const ptr`** | **양쪽 모두** | **상수를 가리키는 상수 포인터**

**값 변경 및 주소 변경 모두 불가능** | `//*ptr = 50; (❌)`

`//ptr = &b; (❌)` |

### 3) `virtual` (가상 키워드)

포인터의 타입이 아닌, **실제로 가리키고 있는 메모리 상의 진짜 객체 함수를 실행하라**고 컴파일러에 지시하는 키워드입니다.

#### `virtual`의 3가지 핵심 형태

| **형태** | **예시 코드** | **역할 및 의미** |
| --- | --- | --- |
| **1. 일반 가상 함수** | `virtual void read()` | 자식 클래스에서 해당 함수를 재정의(오버라이드)할 수 있도록 허용 |
| **2. 순수 가상 함수** | `virtual void read() = 0;` | 자식 클래스가 이 함수를 **반드시 구현하도록 강제** (추상 클래스 형성) |
| **3. 가상 소멸자** | `virtual ~Parent()` | `delete p;` 실행 시 자식 클래스의 소멸자까지 안전하게 순차 호출 보장 |
- **`virtual` 미사용**: 컴파일 시점에 포인터 변수에 적힌 클래스 타입 기준으로 함수 실행 (정적 바인딩)
- **`virtual` 사용**: 포인터 종류와 상관없이 실행 시점(Runtime)에 메모리에 들어있는 실제 객체 타입 기준으로 함수 실행 (동적 바인딩)

### 4) `void` 키워드의 4가지 핵심 용도

`void`는 **'값이 없음'** 또는 '타입이 지정되지 않음(무타입)'을 의미합니다.

1. **반환값이 없는 함수 (`void func()`)**: 함수 실행 후 호출한 측에 결과값을 반환하지 않음
2. **매개변수가 없음을 명시 (`func(void)`)**: 인자를 받지 않는 함수임을 명시 (C++에서는 `func()`와 동일)
3. **범용 포인터 (`void* ptr`)**: 타입에 상관없이 어떤 메모리 주소든 담을 수 있는 포인터 (사용 시 실제 타입으로 캐스팅 필요)
4. **미사용 변수 경고 억제 (`(void)var;`)**: 선언 후 사용하지 않는 변수에 대해 컴파일러 경고(Unused variable warning)를 방지

## 2. ROS2 노드와 실행 모델 (9강)

### 1) ROS2 핵심 개념

- **ROS2 (Robot Operating System 2)**: 로봇 소프트웨어 개발을 위한 오픈소스 **미들웨어(Middleware)** 프레임워크입니다. 하드웨어와 소프트웨어 간 연결을 효율적으로 돕고, 모듈화된 분산 시스템 환경을 제공합니다.
- **노드 (Node)**: 모듈화된 설계의 최소 단위로, **하나의 명확한 기능/일을 수행하는 독립된 실행 프로세스**입니다.
- **노드 간 통신**: 노드들은 메시지(Message)를 **토픽(Topic)**, 서비스(Service), 액션(Action) 등을 통해 주고받습니다.

### 2) ROS2의 주요 특징 및 장점

- **로봇 좌표계 기준 (TF2 & URDF)**:
    - 로봇의 원점(Base Link)은 보통 로봇이 지면에 닿아 있는 **중심/중앙 위치**로 설정합니다.
    - 로봇이 움직일 때 각 관절 및 센서가 원점으로부터 얼마나 이동했는지 3차원 위치 관계를 계산해야 합니다.
    - ROS2의 **`tf2`** 라이브러리와 **`URDF`** (로봇 모델 기술 파일)를 활용하면 위치 변환 연산을 자동으로 처리할 수 있습니다.
- **언어 결합 활용**:
    - 성능 및 정밀 제어가 중요한 개별 노드 로직은 C++로 작성합니다.
    - 노드들을 통합 관리하거나 런치 파일(Launch) 등 실행 제어는 파이썬(Python)으로 구현하여 개발 효율을 높입니다.

### 3) 리눅스 터미널 필수 명령어

#### 환경 및 설정

- `source`: 스크립트 파일의 변경 사항(환경 변수 등)을 현재 셸 세션에 즉시 적용하는 명령어
- `alias`: 자주 사용하는 길고 복잡한 명령어를 짧은 별칭으로 등록하는 기능

#### 경로 관련 기호 및 명령어

- `pwd`: 현재 위치한 디렉토리의 절대 경로를 출력
- `.` : 현재 디렉토리 위치
- `..`: 상위(이전) 디렉토리 위치
- `~` : 사용자 홈 디렉토리 (`/home/username`) 절대 경로

### 4) Navigation2 맵(Map) 저장 명령어

로봇이 생성한 `/map` 토픽 데이터를 기반으로 맵 파일을 저장할 때 사용합니다.

Bash

```
# nav2_map_server 패키지의 map_saver_cli를 사용하여 홈 디렉토리(~)에 map 파일 저장
ros2 run nav2_map_server map_saver_cli -f ~/map
```
